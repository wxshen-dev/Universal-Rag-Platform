# Hi, I'm no-acct-journal

I build backend systems, AI-enabled developer tools, and full-stack product prototypes.
My repositories are mostly hands-on systems work: FastAPI services, RAG pipelines,
terminal coding agents, Vue applications, and Java/Spring Cloud microservice
architectures.

## Current Focus

- RAG and knowledge-base platforms: ingestion, parsing, chunking, hybrid retrieval,
  QA, evaluation, permissions, and background jobs.
- AI developer tooling: streaming agent loops, tool execution, permission models,
  session persistence, memory, skills, sub-agents, worktrees, and MCP integration.
- Java microservices: Spring Boot, Spring Cloud, API gateways, Feign clients,
  service discovery, shared modules, and domain-driven service boundaries.
- Full-stack applications: Vue 3, FastAPI, PostgreSQL, Redis, Docker Compose,
  authentication, caching, and mobile-first UI flows.
